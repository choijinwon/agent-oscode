# 실무 테이블·그리드 기능 분석

2026-09-20. 회계·ERP 전표 조회와 입력을 기준으로 공식 제품 문서를 비교했습니다. 전문가 인터뷰나 사용성 조사 결과를 주장하는 문서가 아닙니다. 아래 우선순위는 반복 작업, 입력 복구, 회계 데이터의 문맥 보존을 기준으로 한 OSCODE의 판단입니다.

| 확인한 요구 | 공식 자료 | OSCODE에 추가한 동작 |
|---|---|---|
| 자주 쓰는 조회 조건을 반복 설정하지 않기 | [SAPUI5 Variant Management](https://help.sap.com/docs/SAPUI5/27c345764bb244f982d5a079f556e564/97fc0eaaf8b045779878ea829586da1a.html) | 검색·필터·정렬·열 표시·행 간격을 이름으로 저장, 적용, 삭제 |
| 업무에 맞는 열만 표시하기 | [TanStack Table Column Pinning 예제](https://tanstack.com/table/latest/docs/framework/react/examples/column-pinning)에서 열 표시·순서·고정 조합 확인 | 선택 열 표시와 행 간격 선택. 회사·통화·금액 등 핵심 열은 유지 |
| 셀 편집 실수와 잘못 붙여넣은 데이터를 복구하기 | [AG Grid Undo/Redo](https://www.ag-grid.com/javascript-data-grid/undo-redo-edits/) | 메모리 내 최근 20단계. 연속 입력, 붙여넣기, 행 추가·삭제, 헤더 변경을 복구 |
| 현재 조회 결과를 다른 도구로 전달하기 | [AG Grid CSV Export](https://www.ag-grid.com/javascript-data-grid/csv-export/) | 선택 행 또는 필터 결과를 CSV로 다운로드. 숨긴 열 포함, 값 이스케이프, 수식 시작 값 중화 |
| 오류 행을 찾아 긴 표를 훑는 시간 줄이기 | [SAP Fiori Grid Table](https://experience.sap.com/fiori-design-web/grid-table/)의 행 상태와 구체적인 오류 설명 원칙 | 오류 위치 수, 이전/다음 이동, 행별 설명 연결과 저장 전 초안 상태 |

직접 작성한 네이티브 HTML UI이며 위 라이브러리의 구현 코드를 가져오거나 유료 기능을 설치하지 않습니다. React·Vue·Angular·Svelte 스타터에서 동일하게 사용할 수 있습니다. 금액은 기존 정수 최소 단위 계산을 유지합니다.

## 의도한 사용 흐름

1. 회사 1000·USD·초안 필터를 선택하고 필요한 열과 간격을 설정합니다.
2. ‘월말 USD 검토’로 보기를 저장합니다. 다시 열 때 목록에서 명시적으로 적용합니다.
3. 표시 행을 검토하고 선택한 행을 CSV로 내보냅니다. 회사와 통화를 함께 전달해 의미가 사라지지 않게 합니다.
4. 전표 그리드에 여러 셀을 붙여넣고, 실수하면 한 번에 되돌립니다.
5. 오류 이동으로 입력을 바로잡고 대차 일치를 확인한 뒤 앱에 초안 이벤트를 전달합니다.

## 경계와 후속 우선순위

- 저장하는 보기는 브라우저·페이지·컴포넌트에 묶인 개인 설정입니다. 조직 공유·서버 동기화·기본 보기 자동 적용은 포함하지 않습니다. 검색어도 조회 조건에 포함됩니다.
- 전표 입력과 복구 이력은 메모리에만 둡니다. 전달 이벤트는 서버 저장 성공이나 감사 기록이 아닙니다.
- CSV 문자열은 정밀도를 유지하지만 Excel의 자동 숫자·날짜 변환은 제어하지 못합니다. 긴 식별자와 금액은 텍스트 열로 가져옵니다. 수식 시작 값은 작은따옴표가 추가되므로 원문과 구분해서 사용합니다.
- 다음 단계는 **실제 데이터 API의 서버 필터·정렬·페이지 이동**, **저장 충돌 감지와 서버 검증 오류 매핑**, **큰 데이터의 가상 스크롤 및 접근성 검증** 순서가 적합합니다. 현재 6행 조회 예시·최대 200행 입력을 대용량 ERP 그리드로 설명하지 않습니다.
- 피벗·수식 엔진·드래그 채우기·세금/환산·SAP 전기는 정확한 업무 규칙과 서버 연결 후 검토합니다. 금융 계산을 임의로 추가하지 않습니다.

검증: 금액·CSV·보기 설정 검증과 실제 브라우저의 저장/복구/다운로드 테스트는 `test/design-erp*.test.js`에서 실행합니다. 사용법은 [디자인 스튜디오](design-studio.md#반복-업무용-보기와-입력-복구)를 참고하세요.
