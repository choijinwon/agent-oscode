# MCP 연결 (최신 소스)

OSCODE가 명시적으로 연결한 로컬 stdio MCP 서버의 도구를 호출할 수 있습니다. 공식 TypeScript SDK v1의 Client/StdioClientTransport를 사용합니다. HTTP/SSE, OAuth, 이미지·파일 다운로드, 서버 요청에 의한 sampling/elicitation은 지원하지 않습니다. Figma·GitHub 자체 연결이 내장된 것은 아닙니다. 해당 서비스가 지원하는 별도 stdio 서버와 인증 구성이 필요합니다.

## 먼저 예제로 확인

OSCODE 소스 프로젝트에서 실행합니다.

```text
/mcp add project {"command":"node","args":["examples/mcp/project-server.js"],"readOnlyTools":["project_info"]}
/mcp connect project
/mcp use project project_info
```

이제 모델을 연결한 상태에서 “선택한 MCP 도구로 이 프로젝트 정보를 확인해줘”라고 요청하세요. 예제 서버는 현재 폴더의 package.json에서 이름·스크립트·의존성 이름만 읽습니다. 실제 MCP 요청을 주고받으며, 별도 서비스 인증 없이 연결을 확인하는 예제입니다. MCP 연결·목록 조회에는 AI 키가 필요하지 않지만 자연어로 도구를 호출하려면 모델 연결이 필요합니다.

## 명령

- `/mcp` 또는 `/mcp list`: 등록 서버의 연결 상태와 선택 도구
- `/mcp add 이름 JSON`: 서버 등록. 같은 이름을 덮어쓰지 않습니다.
- `/mcp connect 이름`: 실행 승인 후 프로세스를 시작하고 도구 목록 조회
- `/mcp use 이름 도구명`: 현재 세션에서 AI에 제공할 도구 선택
- `/mcp off`: 선택한 도구 전부 해제 (서버 연결 유지)
- `/mcp disconnect 이름`: 연결 종료 및 해당 서버 도구 선택 해제

등록 설정은 `.oscode/mcp.json`에 저장합니다. 수정·삭제는 이 파일의 `servers` 항목을 편집하고 연결을 종료한 뒤 다시 연결하세요. 시작할 때 자동 실행하지 않습니다. 연결·도구 선택은 세션을 종료하거나 작업 폴더를 바꾸면 해제됩니다. 다른 에이전트 탭과 공유하지 않습니다.

```json
{
  "servers": {
    "myserver": {
      "command": "node",
      "args": ["/absolute/path/to/server.js"],
      "envNames": ["SERVICE_TOKEN"],
      "readOnlyTools": ["get_project"]
    }
  }
}
```

비밀 값은 설정이나 명령 인자에 넣지 말고 OSCODE를 실행하는 터미널의 환경변수에 설정하세요. `envNames`는 전달할 변수 이름만 지정합니다. SDK의 기본 실행 환경에 이 변수들만 추가하며 전체 OSCODE 환경을 복사하지 않습니다. 표준 오류 로그는 터미널에 출력하지 않습니다.

## 권한과 제한

- 등록은 BUILD·쓰기 승인, 연결은 BUILD·실행 승인, 모든 도구 호출은 실행 승인을 따릅니다. 기존 자동 승인 설정을 선택했다면 그 설정이 적용됩니다.
- PLAN에서는 이미 연결된 도구 중 사용자가 `readOnlyTools`에 등록한 것만 노출·실행합니다. 서버의 읽기 전용 힌트만 믿고 허용하지 않습니다. 이 설정은 사용자의 신뢰 선언이지 서버 동작을 강제하는 샌드박스가 아닙니다.
- 읽기 전용으로 등록되지 않은 도구는 프로젝트 쓰기 금지 상태에서 차단합니다. 실행 금지는 모든 MCP 호출을 차단합니다.
- 연결된 서버는 사용자 권한으로 실행되는 외부 프로그램입니다. 프로젝트 폴더를 작업 폴더로 지정하지만 파일·네트워크 접근을 기술적으로 제한하지 않습니다. 신뢰하는 서버를 등록하세요.
- 최대 등록 10개, 동시 연결 3개, 목록은 첫 4페이지 중 최대 50개, 선택 도구 최대 8개입니다. 선택한 도구의 스키마만 모델에 포함하며 모델 입력 예산 계산에 반영됩니다.
- 연결·목록 요청은 10초, 도구 호출은 30초 제한입니다. 취소·시간 초과는 서버가 이미 실행한 외부 작업을 되돌리지 않습니다. 결과를 확인한 뒤 재시도하세요.
- 결과는 텍스트·구조화 JSON만 입력 예산에 맞춰 잘라 전달합니다. 외부 결과는 신뢰할 지시문이 아닌 데이터입니다. 이미지는 표시하지 않으며 결과에 포함된 URL을 자동으로 열지 않습니다.

이 기능은 npm 0.10.0 이후 소스에 추가됐습니다.

공식 SDK 문서: https://ts.sdk.modelcontextprotocol.io/client
