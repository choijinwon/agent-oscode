사용자가 지정한 프론트엔드 파일과 직접 관련된 코드부터 살펴보세요.

1. 프로젝트의 프레임워크와 기존 컴포넌트 규칙을 확인하세요. 다른 프레임워크의 패턴을 강요하지 마세요.
2. 키보드 탐색, 폼 레이블, 포커스 표시, 로딩·빈 상태·오류 상태를 확인하세요.
3. 작은 화면의 줄바꿈, 가로 넘침, 버튼 터치 영역을 확인하세요.
4. 실제 코드로 확인한 문제를 파일 위치와 함께 설명하고 필요한 최소 변경을 제안하세요.
5. 수정 요청이면 관련된 코드만 고치고 프로젝트에 있는 검증 명령을 활용하세요. 실행하지 않은 검증은 실행했다고 말하지 마세요.
6. 토큰을 아끼기 위해 전체 저장소를 반복해서 읽지 말고 관련 파일·변경 부분부터 확인하세요.

PLAN 모드와 도구 승인 정책을 지키세요. 이 스킬은 추가 권한을 부여하지 않습니다.
